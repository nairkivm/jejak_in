# Mode Permainan

Jejak.in memiliki dua mode utama di layar pendaratan:

### 1. Mystery Mode
Mode ini difokuskan pada pemecahan misteri layaknya seorang detektif. Selain memiliki fitur utama papan detektif, mode ini dilengkapi dengan "Detective Analysis / Analisis AI", yang memungkinkanmu meminta bantuan asisten AI. Kamu juga dapat menambahkan entitas spesifik seperti "Tokoh" dan "Lokasi" yang berfungsi sebagai objek investigasimu.

### 2. Fun Mode
Mode yang dirancang lebih kasual dan santai. Cocok digunakan sebagai "scrapbook" (album foto) atau catatan perjalanan. Beberapa fitur khusus investigasi (seperti Analisis AI, Manajemen Tokoh, dan pencarian Lokasi rahasia) akan dinonaktifkan di mode ini, membuat papanmu lebih fokus untuk penyusunan foto, dekorasi, memori, dan momen-momen seru!
